# 🚨 Emergency Evacuation System Using Graph Algorithms

## 📌 Project Description
This project simulates emergency evacuation planning using graph theory. It finds safest and shortest routes during emergencies like fire, flood, or earthquake.

---

## ⚙️ Features
- Add routes between locations
- Block unsafe routes dynamically
- Display graph structure
- Dijkstra shortest path with actual route
- Floyd Warshall all-pairs shortest paths

---

## 🧠 Algorithms Used
- Dijkstra Algorithm
- Floyd Warshall Algorithm
- Adjacency Matrix Graph

---

## 🛠️ Tech Stack
- Python
- Data Structures (Graph)
- Algorithms
